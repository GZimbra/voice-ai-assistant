# Voice AI Assistant

Assistente de voz em Python que utiliza IA para conversar por áudio.

## Tecnologias

- Python
- Whisper (Speech to Text)
- OpenAI ChatGPT
- Google Text-to-Speech

## Arquitetura

Audio → Whisper → ChatGPT → gTTS → Audio

## Como executar

pip install -r requirements.txt
python main.py
